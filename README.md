## Requirements
Python 3.x

## Run the project

Open Git Bash in the project folder.

```bash
cd Week-01-Cybersecurity-Asset-Inventory
python src/asset_inventory.py
```

If `python` does not work, try:

```bash
python3 src/asset_inventory.py
```
